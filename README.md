### 1. Telegram iOS 苹果版官方原生客户端进入限制群（开车群）的方法

![](https://i.imgur.com/Ba6epuD.png)

开启步骤（三选一即可）：

**方式 a：Windows 电脑桌面客户端**
左上角三短线 → 设置 → 隐私安全 → 开启 "显示含有敏感内容的媒体"

![](https://i.imgur.com/Yl9H4q4.png)

**方式 b：macOS 苹果电脑桌面客户端**
设置 → 隐私安全 → 开启 "显示含有敏感内容的媒体"

**方式 c：网页版**
手机或电脑浏览器访问网页版地址：<https://web.telegram.org/>
对话列表 → 左上角/右上角三短线 → Settings → 打开 "Show Sensitive Content"

> 整体过程就是桌面端或网页版开启显示，手机端就可以了，不需要在手机端 APP 设置中操作。
>
> **要求**：Telegram iOS 客户端版本 ≥ 5.13
>
> **备注**：Windows、macOS、Linux 系统的电脑都可以使用 Telegram Desktop 版本客户端（macOS 上 Mac App Store 中的 "Telegram Desktop" 已更名为 "Telegram Lite"）。
